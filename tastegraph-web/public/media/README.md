# Sample media

These clips are **synthetic**, generated locally with ffmpeg (`lavfi` solid-color sources +
`drawtext`) purely to demonstrate real `<video>` playback in the TasteGraph Web player. They
contain no third-party or copyrighted content.

- `clip_minimal.mp4` — 320×180, 3s, dark solid, label "minimal"
- `clip_street.mp4` — 320×180, 3s, orange solid, label "streetwear"

Replace with your own catalog media (and update `data/tastegraph_media.jsonl` +
`taste-bundle.json`) for a real demo.
